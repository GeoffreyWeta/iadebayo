{% comment %} A YouTube video as a click-to-play poster. Expects `video` — anything with the YouTubeEmbedMixin (Testimonial, SpotlightVideo) — and `label`, the accessible name for the play button. Pass `label` explicitly. The two models name their headline field differently (name vs title), and a `default:` chain across the missing one raises: Django swallows a failed lookup in a plain variable node but re-raises it when it is a filter argument. Why a poster and not an iframe: each live YouTube iframe pulls well over a megabyte of player code before anyone presses play, so a page with six of them is unusable on a phone. Here the browser loads one ~15 KB JPEG and site.js swaps in the real iframe on click. With JavaScript off, the poster is a plain link to YouTube — still watchable. {% endcomment %} {% if video.youtube_embed_url %}
