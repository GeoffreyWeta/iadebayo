# Blog cover images — sources and licence

All five are from **Unsplash**, under the [Unsplash
Licence](https://unsplash.com/license): free to use commercially, no permission
needed, no attribution required. Credits are kept here anyway so the provenance
of anything on the public site is traceable, and so these can be told apart from
photography the Foundation owns.

These are **stock stand-ins**, chosen to match each article's subject. Replace
any of them with the Foundation's own photography when it is available: drop a
16:9 file in at the same name and run

    python manage.py load_posts --refresh-covers

cards show them uncropped and they stay sharp on retina screens.

## Why these five

The site's photography is African throughout, so the covers had to match — a
generic corporate stock look would read as borrowed. Four of the five show Black
or African subjects in working contexts; the fifth is a handshake, chosen for
"delegation and trust" because it carries the idea without putting a face to it.
Several otherwise-decent candidates were rejected for showing Asian or white
subjects, which would have clashed with the rest of the site.
